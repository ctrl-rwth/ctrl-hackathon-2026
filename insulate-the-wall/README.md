# Insulate the Wall

Teach a humanoid robot to insulate a prefab timber wall: one of the softest problems in robotics.

**Robot:** Unitree G1 with Inspire RH56DFQ hands ([3D model](inspire-hand-dfq))

**Data:** [hackathon-2026/challenges/insulate-the-wall](https://huggingface.co/datasets/ctrl-rwth/hackathon-2026/tree/main/challenges/insulate-the-wall) on Hugging Face
