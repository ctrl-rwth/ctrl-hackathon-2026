# Paving the Way

Build a mobile robot that lays a paved area stone by stone, with joints as straight as a pro's.

**Robot:** ABB GoFa on a Clearpath Husky

**Data:** [hackathon-2026/challenges/paving-the-way](https://huggingface.co/datasets/ctrl-rwth/hackathon-2026/tree/main/challenges/paving-the-way) on Hugging Face

**Starter kit:** [smarobix/ctrl-hackathon-2026-kit](https://github.com/smarobix/ctrl-hackathon-2026-kit)

**Laying patterns:** [4 standard patterns for 20 × 10 cm stones, with the position of every stone](laying-patterns)
